Random Password Generator 🔐
📄 Description

This project is a simple HTML + JavaScript web page that generates a random password using letters, numbers, and special characters. When you click the “Generate Password” button, it creates a 6-character random password and logs it to the browser console.

🚀 How to Use

Open the random.html file in any web browser.

Click the “Generate Password” button.

Open your browser’s developer console (Ctrl + Shift + I or F12) to view the generated password.

🧩 Features

Generates passwords of 6 random characters.

Includes lowercase, uppercase, digits, and special characters (@#$&).

Simple, lightweight, and runs entirely in the browser.

🛠️ Technologies Used

HTML5

JavaScript (ES5)
